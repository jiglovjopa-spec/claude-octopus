# Осьминожка для Claude Code

Мод Claude Code: панель «Осьминожка» рядом с чатом, в которой живёт осьминог-питомец.

- Сам переползает с места на место, шевелит щупальцами с присосками, моргает, «дышит».
- **Поболтать:** поле «Скажи осьминожке…» — отвечает от своего лица коротко и по-русски (модель haiku; каждая реплика тратит немного токенов).
- **Погладить:** наведи на него мышку или нажми «✋ Погладить» — розовеет, жмурится, над головой сердечки.
- **Ткнуть:** нажми на него или на «👉 Ткнуть» — выпускает чернильное облако, которое тает через 10 секунд; по кнопке ещё и удирает.
- **Куда ползти:** компас из стрелок ↖ ↑ ↗ / ← • → / ↙ ↓ ↘.
- Пока Claude думает над ответом — пускает пузырьки.

Панель открывается сама при старте сессии, а также командой `/octopus`. В десктопном приложении осьминог векторный, в терминале — пиксельный (там болтают, набирая текст прямо в панели после клика по ней).

## Установка

В терминальной сессии Claude Code:

```
/plugin install octopus --marketplace jiglovjopa-spec/claude-octopus
```

Ответьте `y` на «Add marketplace?», затем выберите область установки.

Из командной строки:

```bash
claude plugin install octopus --marketplace jiglovjopa-spec/claude-octopus
```

В десктопном приложении, где `/plugin` не работает: нажмите «+» рядом с полем ввода, затем Plugins → Add marketplace с `jiglovjopa-spec/claude-octopus`, затем Add plugin.
